# Blender bridge (visualization frontend only)

**Physics stays in C++.** Optional Blender 4.x frontend (Steam or otherwise).

## Install & run (Steam)

See **[INSTALAR_E_RODAR.md](INSTALAR_E_RODAR.md)** — Install from Disk →
`addons/black_hole_bridge/` or `addons/black_hole_bridge.zip` →
sidebar **Black Hole** → **Build Full Scene** → **Bake Orbit Animation**.

Style lock: [`docs/ESTILO_VISUAL_SIMULACAO.md`](../docs/ESTILO_VISUAL_SIMULACAO.md).
